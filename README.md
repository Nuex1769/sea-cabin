# 海上小屋

在海上小屋前的栈桥钓鱼，卖鱼换金币，再把家具摆到平台上。这是一个单文件网页游戏，用浏览器打开即可游玩。

**在线地址：** https://nuex1769.github.io/sea-cabin/

请使用 Chrome、Edge 或 Safari。需要 WebGL。进度自动保存在本机浏览器（localStorage）。

## 玩法

在栈桥上抛竿。浮漂下沉时点「收竿」，然后在指针进入绿色区域时点「拉！」（或按空格）。卖鱼换金币，在商店购买家具，进入「布置」把它们摆在平台上。

## 操作

- **拖动**：旋转视角
- **滚轮 / 双指**：缩放
- **空格**：钓鱼主按钮（抛竿 / 收竿 / 拉）
- **R**：布置时旋转家具
- **回车**：确认放置
- **Esc**：取消或关闭

底部按钮：背包、图鉴、抛竿、商店、布置。右上角可切换白天 / 黄昏 / 夜晚，以及打开设置。

画面由程序生成的几何体组成，页面内嵌 three.js（MIT 许可）。
